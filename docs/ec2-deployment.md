# SmartDine EC2 Production Deployment Guide

## Server & Domain Information
- **Domain**: `smartdine.aslijarvis.ninja`
- **Server IP**: `13.53.190.53` (AWS EC2)
- **Frontend Port**: `3000` (Next.js)
- **Backend API Port**: `8000` (FastAPI)
- **Reverse Proxy**: Nginx (Port 80 -> Port 443 with Let's Encrypt SSL)

## 3. Install Nginx & Apply Configuration
```bash
sudo cp deploy/nginx-smartdine.conf /etc/nginx/sites-available/smartdine
sudo ln -sf /etc/nginx/sites-available/smartdine /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

---

## 4. Install Free SSL with Certbot
```bash
sudo certbot --nginx -d smartdine.aslijarvis.ninja
```
Certbot will automatically configure HTTPS redirect and renew certificates.

## 5. QR Code Verification
Once deployed, all receipt review QR codes generated by the cashier portal will embed:
`https://smartdine.aslijarvis.ninja/review?token=...`
Guests can scan the QR code from their mobile phone camera over any cellular network or Wi-Fi to submit their feedback.
